# LMS для Олимпиадной Школы "Общее Дело"

## 🎯 О проекте

Платформа для управления обучением по гуманитарным предметам:
- **Обществознание**
- **Право**
- **Русский язык**
- **Литература**

**Целевая аудитория:**
- 20 кураторов
- 700 учеников
- Подготовка к олимпиадам и ЕГЭ

## 🎨 ФИЧИ ДЛЯ POST-MVP

### Месяц 2: Расширенный функционал

#### 1. Система баллов
```typescript
interface Assignment {
  maxScore: number; // Макс. балл за задание
  criteria: Criteria[]; // Критерии оценивания
}

interface Criteria {
  name: string;
  maxScore: number;
  description: string;
}
```

**UI:**
- Оценивание по критериям (как в ЕГЭ)
- Автоподсчет итоговой оценки
- Рейтинг учеников
- Статистика по баллам

#### 2. Календарь и дедлайны
- Календарь заданий
- Напоминания за 3 дня / 1 день / 3 часа
- Расписание занятий
- График олимпиад

#### 3. Теги и фильтры
```typescript
type Subject = 'обществознание' | 'право' | 'русский' | 'литература';
type Topic = 'эссе' | 'анализ' | 'сочинение' | 'тест' | 'теория';
type OlympiadType = 'всош' | 'высшая проба' | 'ломоносов' | 'егэ';

interface Assignment {
  subject: Subject;
  topics: string[];
  olympiadType?: OlympiadType;
  difficulty: 'easy' | 'medium' | 'hard';
}
```

**Фильтры:**
- По предмету
- По типу задания
- По олимпиаде
- По сложности
- По статусу выполнения

#### 4. Материалы и теория
```typescript
interface Material {
  type: 'video' | 'article' | 'pdf' | 'link';
  title: string;
  url: string;
  subject: Subject;
  topics: string[];
}
```

**Разделы:**
- База знаний
- Конспекты
- Видео-разборы
- Полезные ссылки
- Рекомендации по темам

#### 5. Аналитика и отчеты
**Для учеников:**
- График прогресса
- Слабые темы
- Рекомендации

**Для кураторов:**
- Экспорт оценок в Excel
- Отчет по группе
- Сравнение групп

**Для менеджера:**
- Dashboard с метриками
- Активность платформы
- Retention учеников

#### 6. Комментарии и обсуждения
- Комментарии к заданию
- Вопросы куратору
- Форум/чат группы
